# End-User Frontend V1 Visual System Prototype

> Historical prototype. It describes a retired browser product proposal and is not a current implementation target.

Question: Which visual system makes Vegapunk feel like a serious scientific workbench rather than an admin dashboard or marketing page?

Three structurally different variants of a completed Discovery Launch Results page were compared in desktop and mobile browsers.
The selected Evidence Ledger variant remains as the durable reference page.

Run the prototype with one command from the repository root:

```bash
python3 -m http.server 4174 --directory docs/prototypes/end-user-frontend-v1-visual-system
```

Open `http://127.0.0.1:4174/`.

## Verdict

Use Evidence Ledger as the Version 1 visual-system baseline.
It keeps work identity, lifecycle, the primary result, scientific evidence, and curated outputs visible without taking on the editorial posture of Research Notebook or the developer-console posture of Experiment Matrix.
The detailed rules are recorded in [End-User Frontend V1 Visual System](../../research/end-user-frontend-v1-visual-system.md).

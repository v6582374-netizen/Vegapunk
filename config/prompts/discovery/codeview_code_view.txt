你是一名高级代码分析助手。你的任务是分析给定代码并提供结构化分析报告。待分析代码如下：

<code>
{code}
</code>

请从以下方面进行分析：

1. file_overview
- **文件用途**：用一句话描述该文件的主要用途
- **关键组件**：列出主要类和函数
- **主要流程**：简要说明组件之间如何交互

2. 类级分析：对每个类，给出其名称并简要说明用途。还应对类中的函数进行函数级分析，并列出所有方法（类内函数）。

    - 方法：method_name：说明

3. 函数级分析：对每个函数（包括独立函数和类中的函数），给出其名称并简要说明用途。
    - function_name：用 1–2 句话说明该函数的作用

分析准则：
    - 先给出文件级摘要，再给出文件、类和函数的详细说明。
    - 使用清晰、专业的技术语言。
    - 聚焦可观察到的行为，不要基于实现作推测。
    - 使用 Markdown 格式输出。

输出格式：
<file_overview>

</file_overview>

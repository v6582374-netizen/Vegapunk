## Question

What end-to-end and component-level acceptance gates prove that the Native Desktop Discovery Module is ready to replace the current entry surface without leaking into New Session or depending on the obsolete Web Unified Workspace architecture?
The decision must define the supported migration boundary, required UI and API tests, restart and reconnect coverage, and the exact legacy surfaces that remain or are removed.

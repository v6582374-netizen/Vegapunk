# Witness the reset

Type: grilling
Status: open
Labels: wayfinder:grilling
Blocked by: 15, 17

## Question

What establishes that the world is actually back at the start of an episode,
when no human is present to attest it?

`ResetRecord` is a named human's testimony: lid closed, vessel restored, cup at
its start pose. Inside a self-turning batch there is no such human, so either
reset becomes witnessed fact or the batch runs episodes from an unknown state
and every conclusion drawn from it is void.

Resolve:

- which reset facts the bench witness can establish, and which it cannot
- what the robot itself performs as part of the reversible core versus what
  needs no action because nothing moved
- the rule when a reset fact cannot be established: the batch stops and waits
  for a human, on the same principle as the pour gate — an unestablished fact is
  never assumed
- how a witnessed reset is recorded so that a batch's episodes are comparable as
  evidence, and how it is distinguished from a human-attested reset
- what invalidates the whole batch retroactively if reset drift is discovered

This is the pour gate's rule moved to the episode boundary: the same refusal to
treat an assumption as an observation, applied to the start of a run rather than
to its one irreversible act.

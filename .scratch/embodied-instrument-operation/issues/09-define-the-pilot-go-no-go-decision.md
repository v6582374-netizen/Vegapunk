# Define the pilot go/no-go decision

Type: grilling
Status: open
Labels: wayfinder:grilling
Blocked by: 05, 06, 07

## Question

After the 20-episode pilot is trained and evaluated, what evidence decides
whether to collect more demonstrations, revise the task/data contract, or
stop this learning formulation?

Resolve held-out episode construction, supervised hardware scope, success and
safety measures, failure taxonomy, review roles, and the exact decisions each
result opens. This decision must prevent dataset scaling from becoming a
substitute for diagnosis.

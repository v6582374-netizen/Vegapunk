# Decide the approach corridor's visual structure

Type: grilling
Status: open
Labels: wayfinder:grilling
Blocked by: 02, 13

## Question

Is the room's existing visual structure sufficient for a vision-only approach,
and if not, what may legitimately be added?

The captured scene is white drapery against white reflective tile: the
instrument and its table are close to the only features in it. Root motion is
authored from vision alone, so the approach's entire feedback signal rests on
that one object staying resolvable at distance.

Decide whether the corridor needs added structure — floor texture, fiducials,
background contrast, lighting — and if so, resolve the risk it introduces: a
policy that keys on an added marker has learned the marker, not the
instrument, and the marker then becomes part of the configuration every later
episode must reproduce. Distinguish structure that makes the instrument more
resolvable from structure that becomes a substitute target.

Any added marker is still Positional Evidence only while it is visible;
nothing here may reintroduce dead reckoning.
